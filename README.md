# Blood Donation Management System

A web-based Blood Donation Management System developed using Java Spring Boot, MySQL, HTML, CSS, and JavaScript.

## Features

- Donor Registration
- Hospital Registration
- Blood Request Management
- Admin Approval and Rejection
- Approved Donor Management
- Approved Hospital Management
- Blood Compatibility Checking
- Matching Blood Requests
- Notifications
- Blood Statistics
- Reports and Charts
- PDF Generation for Matching Requests

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript
- Chart.js
- jsPDF

### Backend
- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- Maven

### Database
- MySQL
